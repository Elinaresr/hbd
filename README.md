# Regalo de cumpleaños — retratos

Página web vertical y mobile-first con 24 fotografías. Cada imagen aparece completa dentro de un marco independiente; ninguna se utiliza como fondo ni se recorta para llenar la pantalla.

La experiencia comienza con una portada anime morada y un acertijo de cumpleaños. La respuesta válida es `ATUN` o `ATÚN`.

## Abrir

Abre `dist/index.html` en el navegador.

## Cambiar fotos

Las imágenes están en `dist/assets/photos/` y se llaman `01.webp` a `24.webp`. Conserva esos nombres al reemplazarlas.

## Efectos

Los retratos reciben un efecto distinto de forma aleatoria en cada carga. La página respeta la preferencia del sistema para reducir movimiento.

Las fotos 20–24 responden al toque mostrando frases aleatorias. La tarjeta de sorpresa también cambia su mensaje cada vez que se pulsa.
